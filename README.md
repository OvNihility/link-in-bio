# Link in Bio

A polished, mobile-first personal link-in-bio page.

## Live Site

Enable GitHub Pages to host this for free:

1. Go to **Settings** → **Pages**
2. Under **Build and deployment**, set Source to **Deploy from a branch**
3. Select `main` branch and `/ (root)`
4. Save — your site will be live at `https://ovnihility.github.io/link-in-bio/`

## Customization

Edit `index.html` to personalize:

- Change the avatar initials or replace the `.avatar` div with an `<img>` tag
- Update your name, bio, and link URLs
- Add/remove buttons as needed
- Swap Font Awesome icons (class names like `fab fa-instagram`)

## Preview

Open `index.html` locally in any browser, or use the GitHub Pages URL once enabled.
